    Band Data¶

    These are the practical wavelength windows used by the project for identifying and integrating spectral lines. Each window defines the extraction boundaries (in nm) around a line of interest.

    Note

    These entries should be kept synchronized with the corresponding data source in the code. Do not edit the table here without also updating the source data file.
